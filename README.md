# TokenLab: Interactive Tokenisation Visualiser

## Project Description

TokenLab is a web-based project that is built on a browser to assist users to learn about tokenisation in Natural Language Processing (NLP). Making raw text into smaller units referred to as tokens is called tokenisation, and it is one of the initial steps in nearly all NLP pipelines.

The user is able to type in any text and view in real time how it is separated into tokens with various tokenisation strategies. It is designed as a learning tool and therefore an abstract concept of NLP is made concrete and available without any programming skills and software that need to be installed.

---

## Features

- Tokenisation in real time whilst typing or entering text.
- Supported multiple tokenisation techniques.
- Colour-coded output of individual tokens.
- Dynamic number of tokens.
- Comparison between methods side-by-side through a comparison page.
- Responsive clean interface, usable by desktop and mobile browsers.
- Can be run in the browser.

No build tools or dependencies are required.

1. Clone or download the repository.
2. Open any modern web-based browser with index.html.

---

## How to Use

1. Open the application in your browser.
2. Enter any text in the input box of the home page.
3. Choose a tokenisation technique among the possible ones.
4. Press Tokenise 
5. The tokenised output will be displayed below in a visualised fashion with each token separated.
6. The number of tokens is shown below the output.
7. Compare methods at once by going to the **Compare** page in the navigation bar.
